WHAT DOES VARNAAKSHARA DO?

  Type in English → Get output in Indian scripts!
  Works system-wide in every application.

  Supported languages (12):
  • অসমীয়া  Assamese        • বাংলা  Bengali
  • ગુજરાતી  Gujarati        • हिन्दी  Hindi
  • ಕನ್ನಡ  Kannada          • മലയാളം  Malayalam
  • मराठी  Marathi           • ଓଡ଼ିଆ  Odia
  • ਪੰਜਾਬੀ  Punjabi          • संस्कृतम्  Sanskrit
  • தமிழ்  Tamil             • తెలుగు  Telugu

  Example: Type "namaskara" → ನಮಸ್ಕಾರ

  Both Baraha and ITRANS transliteration schemes.
  Custom key mappings supported.

WHAT WILL BE INSTALLED?

  ✓ Varnaakshara IME application
  ✓ 7 Unicode fonts (Noto Sans — one per script)
  ✓ 2 Vedic fonts (patched for Vedic diacritics)
  ✓ 23 ANSI legacy fonts (BRH series)
  ✓ Start Menu shortcut
  ✓ Desktop shortcut (optional)
  ✓ Auto-start with Windows (optional)

HOW TO USE:

  • Press F11 to toggle IME on/off
  • Press F12 to open the Settings window
  • Press Ctrl+1 through Ctrl+= to switch languages
  • Double-click the tray icon to toggle IME
  • Left-click or right-click the tray icon for menu

  The app starts in English mode by default.
  Toggle it on when you want to type in an Indian script.

IMPORTANT NOTES:

  • No admin rights required — installs to your profile.
  • No existing fonts will be modified or replaced.
  • No internet connection required — works fully offline.
  • Word suggestions are experimental and off by default.
    Enable them in Settings → Behavior if you want to try.
  • This software is FREE and NOT FOR SALE.
