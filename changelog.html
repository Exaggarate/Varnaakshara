What's new

Every release, every fix, every feature. Follow the journey from v1.0.0 to now.

v1.3.0 Latest June 19, 2026
Async Suggestions & Custom Mappings

🔧 Stability

  • Async suggestion engine — dedicated worker thread with queue draining. Suggestions never block the keyboard hook.
  • Qt thread safety — cross-thread popup calls use QApplication.postEvent with a custom invoker pattern
  • Background word learning — SQLite writes happen off the main thread

✨ Features

  • Word suggestions (experimental, opt-in) — learns from your typing over time
  • Custom Mappings Editor — define your own transliteration overrides in-app
  • Typing Reference — interactive dialog showing all key-to-character mappings
  • Left-click tray opens menu (right-click also works, double-click toggles IME)
  • Starts in English mode by default — press F11 to activate

🎨 UI

  • High-DPI and multi-monitor support
  • Dark theme with proper Indic character rendering
  • Window icon set on all dialogs

v1.2.0 June 18, 2026
Bug Fixes & Vedic Support

🐛 Major Bug Fixes

  • Smart Backspace — diff-based, removes one transliteration step per press
  • Danda fix — | and || no longer cause spurious virama
  • Multi-char symbol priority — || and ## checked before single chars

🐛 Minor Bug Fixes

  • Avagraha fix — & now correctly produces avagraha (अवग्रह)
  • OM symbol fix — OM. produces Om symbol; OM alone stays as-is

✨ New Features

  • Vedic swaras — #, $, ## for svarita, anudatta, dirgha svarita
  • Suggestion popup rewrite — 14pt font, 3-tier caret positioning
Download v1.2.0
v1.1.0 June 15, 2026
Stability & Auto-updater

🐛 Bug Fixes

  • Shift+symbols (?, !, @, #) now work correctly in all languages
  • Period stays as period — no longer converts to danda
  • Fixed crash when typing digits in Indic mode

✨ New Features

  • Native script digits — typing 0-9 outputs native numerals
  • Auto-updater — checks for updates on startup, one-click update
  • Post-update notification shows what changed

🔄 Improvements

  • Removed toast notifications on language switch — cleaner experience
  • Version displayed in About dialog and tray menu

v1.0.0 June 15, 2026
Initial Release 🎉

🚀 Launch Features

  • 12 Indian languages — Assamese, Bengali, Gujarati, Hindi, Kannada, Malayalam, Marathi, Odia, Punjabi, Sanskrit, Tamil, Telugu
  • System-wide IME — works in any Windows application
  • Baraha-compatible phonetic transliteration
  • Implicit schwa for Hindi/Marathi/Bengali
  • Proper Sanskrit halant handling
  • Candra vowels for Hindi loanwords (ऑफ़िस, डॉक्टर)
  • Includes Indic fonts for all 12 scripts
  • Start with Windows option
  • F11/F12 toggle, Ctrl+1-9 for direct language pick

No admin required — installs to your user profile. Free, offline, open source.
