# Varnaakshara IME

**Type in 12+ Indian languages using English transliteration.** Free system-wide input method for Windows.

## Supported Languages
Hindi, Tamil, Telugu, Kannada, Malayalam, Bengali, Gujarati, Marathi, Punjabi, Odia, Assamese, Sanskrit, and more.

## Download

Head to [**Releases**](https://github.com/Exaggarate/Varnaakshara/releases) to download the latest installer (.exe).

## Features
- System-wide transliteration (works in any app)
- Smart suggestions with async popup
- Custom key mappings
- Multi-language support
- Lightweight, runs in system tray
